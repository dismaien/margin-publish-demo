Welcome to the Margin demo

This folder is entirely synthetic. It exists to show how Margin edits ordinary Markdown files without importing them anywhere.

Try this

Move the caret onto a line with formatting. The Markdown characters appear so you can edit them, and fade away again when you move on.

What's here

  • Field Notes — a longer piece with several headings (open the outline with ⌃⌘I).
  • Style Guide — tables, code, and quotes.
  • Ideas and Reading List in the garden.
  • Cardamom Buns, because every notebook needs a recipe.
  • A synthetic Plume transcript in Transcripts/.

Things to try

  • Open this folder with File ▸ Open Folder…
  • Click a checkbox to toggle it
  • Press ⌘/ to switch between Live and Source
  • Publish a few notes with File ▸ Publish Site…

Private notes such as the journal stay private unless you check them in the publish window. Links to them from published pages become plain text.

Written with care and #markdown.
